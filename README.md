\# SpikeProcessorII



SpikeProcessorII is an open-source MATLAB framework for flexible multielectrode array (MEA) experiments using the Multichannel Systems MEA2100 platform.



SpikeProcessorII provides a modular framework for hardware communication, real-time spike detection, visualization, data acquisition, electrical stimulation, and closed-loop experimental control in electrophysiological research.



\## Features



\- Real-time spike detection

\- Electrical stimulation

\- Closed-loop feedback

\- Data acquisition and storage

\- Modular framework architecture
